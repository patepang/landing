# Plus Jakarta Sans

- **Family:** Plus Jakarta Sans by the Plus Jakarta Sans Project Authors
  (https://github.com/tokotype/PlusJakartaSans), the typeface of the Patepang app.
- **Files:** `plus-jakarta-sans-latin-{400,500,600,700}-normal.woff2`, the latin subset of the
  four static weights the design system uses.
- **Taken from:** npm package `@fontsource/plus-jakarta-sans@5.3.0` (published 2026-07-19). The
  tarball's SHA-1 `a1c37aec60423dd44476d9da00bd34ce546ee859` matched the registry's `dist.shasum`
  before the files were copied. The package is not a dependency of the landing; only these files
  were copied.
